# SQL & Data Analytics Portfolio

Welcome to my data analytics and SQL portfolio repository. This repository showcases end-to-end analytics projects featuring database querying, data cleaning, CTE analytical pipelines, and dashboard visualizations.

## Projects Summary

### 1. [Financial Fraud Risk & Velocity Analysis](./Financial-Fraud-Detection-PaySim)
* **Tech Stack:** SQLite 3, Advanced SQL (Window Functions, CTEs), Tableau Public
* **Domain:** Financial Services / Fraud Operations
* **Focus:** Analyzed 6.36M+ transaction records using PaySim data to identify multi-step money laundering schemes, 24-hour volumetric anomaly spikes, and high-velocity account depletion.

### 2. [HR Employee Attrition & Workforce Analysis](./HR-Employee-Attrition-Analysis)
* **Tech Stack:** SQL, Data Modeling, Tableau / Excel
* **Domain:** Human Resources Analytics
* **Focus:** Evaluated key workforce demographic indicators, job role satisfaction levels, and compensation metrics driving employee turnover.

### 3. [UFO Sightings Exploratory Data Analysis](./UFO-Sightings-Analysis)
* **Tech Stack:** SQLite 3, Data Cleaning, SQL Aggregations
* **Domain:** Exploratory Data Analysis
* **Focus:** Scrubbed and standardized observational sighting logs to analyze global geographic patterns and temporal sighting distributions.
