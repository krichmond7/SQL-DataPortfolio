# UFO Sightings Data Analysis

## Project Overview
An Exploratory Data Analysis (EDA) and data cleansing project evaluating global UFO sighting reports, geographic clusters, and duration patterns using scrubbed observational data.

## Key Analytical Focus
- **Data Cleansing:** Standardized inconsistent duration strings, geographic coordinates, and timestamp formatting.
- **Geographic Distribution:** Aggregated sighting frequency by country, state, and city to identify reporting hotspots.
- **Temporal Analysis:** Evaluated seasonal and daily time-of-day trends in reported encounters.

## Tech Stack
- **Database / Tooling:** SQLite 3 / Python
- **Data Source:** Scrubbed UFO Sightings Dataset
